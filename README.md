# ANGEL.OS — portfolio

Black & white cyber-angel × 8-bit DOS. A Next.js site that boots like a
terminal, then shows a live, self-updating profile.

**Live:** https://afaguayo.github.io/PortfolioWeb/

The app itself lives in [`my-portfolio/`](my-portfolio) — see that folder's
[README](my-portfolio/README.md) for the stack, local dev, and how the page
keeps itself up to date (age, GitHub projects, Spotify/Steam top 5) without a
redeploy.

## Stack

Next.js 15 (static export) · React 19 · TypeScript · Tailwind · Framer Motion
· deployed free to GitHub Pages via `.github/workflows/pages.yml` on every
push to `main`.
